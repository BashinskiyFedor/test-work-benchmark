# Последовательное тестирование скорости скачивания

Небольшой консольный скрипт на Node.js, который скачивает один и тот же ресурс по указанному URL **10 раз последовательно**.

Каждый запрос полностью завершается (включая получение всего тела ответа) до начала следующего.

## Требования

- Node.js версии 18 или новее (используется встроенный API `fetch`).
- Доступ к интернету и целевому URL.

Сторонние зависимости не требуются.

## Запуск

```bash
node main.js "https://example.com/large-image.jpg"
```

Замените URL на адрес ресурса, скорость скачивания которого хотите измерить. Поддерживаются адреса с протоколами `http://` и `https://`.

## Что измеряет скрипт

Для каждого запроса скрипт выводит HTTP-статус, время выполнения и объём скачанных данных.

После выполнения всех 10 запросов выводится итоговая статистика:

- **Среднее время запроса** — среднее арифметическое времени выполнения всех 10 запросов, в миллисекундах (`ms`).
- **Общий объём скачанных данных** — сумма размеров тел всех полученных ответов, в мебибайтах (`MiB`; 1 MiB = 1 048 576 байт).
- **Средняя скорость скачивания** — общий объём полученных данных, разделённый на суммарное время выполнения всех запросов, в мебибайтах в секунду (`MiB/s`).

Отсчёт времени начинается непосредственно перед вызовом `fetch()` и заканчивается только после полного получения тела ответа.

Количество скачанных данных определяется непосредственно по потоку ответа (`response.body`), а не по заголовку `Content-Length`.

Запросы выполняются строго последовательно, а не параллельно.

Если сервер вернёт HTTP-статус, не относящийся к диапазону успешных ответов (2xx), или произойдёт сетевая ошибка, выполнение скрипта будет остановлено с ненулевым кодом завершения.
